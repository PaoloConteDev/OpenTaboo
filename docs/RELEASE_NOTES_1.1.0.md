# Open Taboo 1.1.0

## What's new

- Create multiple custom decks, each with its own name and colour.
- Add and edit cards with one target word and five forbidden words.
- Custom decks belong to the language selected when you create them.
- Mix custom decks with each other and with the six included decks.
- Browse included and custom decks in separate sections, with the create button below your custom decks.
- Save decks on your device and keep saved matches intact when decks are edited or deleted.

## Install or update

Download the attached `Open-Taboo-v1.1.0.apk` on your Android phone and open it. If Open Taboo is already installed, choose **Update** and keep the existing installation to preserve your data.

Version: **1.1.0** · Android build code: **2**. The package and signing certificate are the same as the previous release.
