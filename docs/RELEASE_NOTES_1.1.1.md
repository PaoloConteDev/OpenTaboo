# Open Taboo 1.1.1

## What's new

- Remove the match history section ("Moments of glory") and its trophy button.
- Show a gear icon for settings.
- Add a link to the GitHub repository directly below the app version in settings.

## Install or update

Download the attached `Open-Taboo-v1.1.1.apk` on your Android phone and open it. If Open Taboo is already installed, choose **Update** and keep the existing installation to preserve your preferences, custom decks, and current match. Completed-match history has been removed in this version.

Version: **1.1.1** · Android build code: **3**.
